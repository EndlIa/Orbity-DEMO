# Orbity Spec 0.1（实验草案）

本草案服务于本地原型，尚非行业标准。资产以注册表提供 `manifest` 与 `create(params)`；创建函数返回 `THREE.Object3D`，宿主负责场景、相机和渲染循环。当前实现通过重建对象应用参数，宿主负责释放几何体和材质；共享资源和贴图的所有权尚未定义。

清单包含 `specVersion`、小写连字符 `id`、`name` 和 `parameters`。参数类型暂限 number（默认值、最小值、最大值）、color（六位十六进制）、boolean（默认值）。场景 v1 保存资产 id、实例 id、参数、位置和 Y 轴旋转。重开时使用本地注册表；没有版本锁定、导入代码、依赖解析、动画生命周期或安全隔离，故不能保证跨版本复现。

下一步应使用固定版本的真实 img2threejs 和 EZ-Tree 样本，分别写独立适配器；添加资产版本、完整变换、资源所有权及 update/dispose 契约，并在两个不同宿主进行互操作测试。分析器仅用正则提供提示，不能证明代码有效、兼容或安全。
